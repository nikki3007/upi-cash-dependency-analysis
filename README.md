# Analyzing the Impact of UPI Adoption on Cash Dependency

## Team 11

### Project Overview
This project analyzes the relationship between the growth of Unified Payments Interface (UPI) transactions and changes in ATM cash withdrawals in India from 2019 to 2023.

We compare public sector banks and private sector banks to investigate whether the growth of digital payments is associated with different reductions in cash withdrawals across the two banking sectors.

### Research Question
Did the surge in UPI transactions between 2019 and 2023 lead to a statistically significant, disproportionate reduction in ATM cash withdrawals for private sector banks compared with public sector banks?

### Data Sources
- **RBI Database on Indian Economy (DBIE):** Bank-wise ATM/POS/Card statistics, including monthly ATM withdrawal data.  
  https://rbi.org.in/scripts/ATMView.aspx
- **National Payments Corporation of India (NPCI):** Monthly UPI transaction statistics.  
  https://www.npci.org.in/product/upi/product-statistics

### Tools and Technologies
- Python
- pandas for data cleaning and processing
- SciPy for statistical analysis and hypothesis testing
- Power BI or Tableau for interactive data visualization

### Planned Methodology
1. Collect ATM withdrawal data from RBI and UPI transaction data from NPCI.
2. Clean, filter, and combine the datasets using pandas.
3. Compare ATM withdrawal trends for public and private sector banks.
4. Conduct statistical analysis, including two-sample t-tests and confidence intervals, as appropriate for the data.
5. Present the findings through an interactive dashboard.
